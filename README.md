# 🏠 HomeServe
HomeServe is a modern React web app that helps users find and book local home services such as cleaning, plumbing, electrical work, lawn care, snow removal, and handyman tasks.  
It’s designed as a real-world, consumer-friendly project that showcases practical UI, clean design, and API integration.

## 🌟 Features

### 🔧 Browse Services
Explore popular home services with clear categories:
- Cleaning
- Plumbing
- Electrical
- Lawn Care
- Snow Removal
- Handyman

### 📄 Service Details
Each service includes:
- Description
- Price range
- What’s included
- Provider info
- Customer reviews
- “Book Now” button

### 📅 Booking System
Users can:
- Pick a date and time  
- Enter address  
- Add notes  
- Confirm booking  

### 👤 Provider Profiles
View provider details:
- Photo  
- Skills  
- Rating  
- Completed jobs  

### 🗺️ Location Search (Optional)
Search cities and addresses using free APIs.

## 🛠️ Tech Stack
- React + Vite  
- React Router  
- TailwindCSS  
- Reusable components

---

## 🔌 APIs Used
HomeServe uses free, public REST APIs for data:

- **GeoDB Cities API** — city search  
- **DummyJSON** — providers, reviews, mock data  
- **JSONPlaceholder** — booking simulation  
- **OpenStreetMap / Nominatim** — address lookup  
- **Open-Meteo** — weather for outdoor services
